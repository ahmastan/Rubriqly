# Security

## Reporting a vulnerability

Please report security problems **privately**, not in a public issue:

- **Preferred:** GitHub → this repository → **Security** → **Report a vulnerability**.
- Or email **contact@rubriqly.com** with "Security" in the subject.

Include what you found, how to reproduce it and what an attacker could do. We'll acknowledge your report as soon as we can, keep you updated, and credit you (if you'd like) once it's fixed.

Please don't access other people's accounts or data, and don't run tests that could disrupt the service or run up its costs (for example, mass sign-ups or checks) on rubriqly.com. Use your own local copy instead: see the README.

## Scope

This covers the code in this repository and the hosted service at rubriqly.com. Problems in third-party services (Render, Neon, Vercel, TypeSafe AI) should go to those providers.
